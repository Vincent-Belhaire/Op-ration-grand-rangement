# Séance 4 TICE 6e — Opération grand rangement

Mini-site autonome en HTML, CSS et JavaScript. Aucune installation ni dépendance externe n’est nécessaire.

## Tester sur un ordinateur

Ouvrir `index.html` dans un navigateur récent. Pour tester tous les raccourcis clavier, cliquer dans la page avant d’appuyer sur les touches.

## Publier avec GitHub Pages

1. Créer un nouveau dépôt GitHub, par exemple `operation-grand-rangement`.
2. Déposer `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans GitHub, ouvrir **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. Attendre une à deux minutes : l’adresse publique apparaît dans la même page.

Le site fonctionne sans connexion une fois les trois fichiers chargés. Tous les noms d’élèves utilisés dans les défis sont fictifs.
